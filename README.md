## 🎂 About Rose Cake House
**Rose Cake House** is a premium headless e-commerce storefront built for an luxury artisan bakery in Sri Lanka. It combines modern web performance with a high-end luxury aesthetic, features interactive custom cake design tools, multi-currency Sri Lankan localization (LKR), and seamless headless checkout.

---

## ✨ Key Features
- **🌹 Brand Aesthetic**: Soft-luxury bakery aesthetic inspired by Magnolia Bakery, Milk Bar, Framer, and Stripe.
- **🎨 Interactive 3D Live Cake Studio (`/custom-cake`)**: Real-time multi-tier cake builder with dynamic shape, flavor, filling ribbon, color swatches, toppings, and handwritten text preview.
- **🛍️ Headless Shopify Integration**: Live GraphQL Storefront API fetching with resilient fallback to high-resolution luxury datasets.
- **🇱🇰 Sri Lankan Localization**: Prices formatted in Sri Lankan Rupees (**LKR / Rs.**), islandwide shipping calculations (Free delivery for orders above Rs. 6,000), local Colombo boutique addresses, and PayHere / Koko / Mintpay payment options.
- **🛒 Express Checkout Drawer**: Slide-in cart drawer with coupon validation (`LUXURY10`, `FIRST15`), quantity controls, and order summary.
- **📱 Mobile-First Responsive**: Fully optimized for desktop, tablet, and mobile with bottom navigation bar and WhatsApp concierge button.

## 🚀 Getting Started Locally

```bash
# Clone repository
git clone https://github.com/twelizadigtial/rose-cake-house.git
cd rose-cake-house

# Install dependencies
npm install

# Configure environment variables (.env.local)
SHOPIFY_STORE_DOMAIN=v0wx1y-j9.myshopify.com
SHOPIFY_STOREFRONT_TOKEN=4da05625b45b8060f79df66f868f69cf

# Run dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application locally.
